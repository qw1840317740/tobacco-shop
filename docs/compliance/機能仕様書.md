## 2. 年齢確認メカニズム

### 2.1 概要

日本たばこ事業法第 39 条（広告の制限）および関連自治体の青少年保護条例に基づき、未成年者（20 歳未満）の閲覧・購入を防止するため、**二段階の年齢確認**を実装しています。

| 段階 | 名称 | 目的 | 確認方法 |
|------|------|------|----------|
| 第1段階 | サイト入口年齢ゲート | サイト閲覧前の年齢宣言 | 「私は法定年齢です」ボタン押下 |
| 第2段階 | 購入時本人性確認 | 注文前の厳格な年齢確認 | 公的証明書（運転免許証・健康保険証・マイナンバーカード・パスポート）のアップロード＋管理者による目視審査 |

### 2.2 第1段階：入口年齢ゲート

#### フローチャート

```
[任意の URL にアクセス]
        │
        ▼
[Edge Middleware がクッキー age_verified を確認]
        │
   ┌────┴────┐
   │         │
 未保持     保持済み
   │         │
   ▼         ▼
/age-verify   通常ページを表示
へリダイレクト   （クローラは除外）
```

#### 実装場所

- **リダイレクト判定**：[`src/middleware.ts`](src/middleware.ts) 行 99-103
- **年齢ゲート画面**：[`src/app/[locale]/age-verify/page.tsx`](src/app/[locale]/age-verify/page.tsx)
- **クローラ除外リスト**（Google・Bing 等の検索エンジンを年齢ゲート対象から除外）：
  - Googlebot / Googlebot-Image / Mediapartners-Google
  - bingbot / Slurp / DuckDuckBot / Baiduspider / YandexBot
  - facebookexternalhit / Twitterbot / LinkedInBot
  - AhrefsBot / MJ12bot / SemrushBot

#### 年齢ゲート画面の仕様

| 要素 | 内容 |
|------|------|
| タイトル | 「年齢確認」 |
| 警告文 | 「このサイトに入るには、お住まいの国の喫煙可能年齢である必要があります」 |
| 主ボタン | 「私は法定年齢です」（押下すると `age_verified=1` クッキーを設定し、元の URL またはホームへ遷移） |
| 副ボタン | 「私は未成年です」（押下すると「お断りします」ページを表示） |
| 補足文 | 「このサイトに入ることで、お住まいの管轄区域でたばこ製品を購入する法的年齢であることを確認します」 |

#### クッキーの設定

```
age_verified=1; Path=/; SameSite=Lax
```

- セッションクッキー（`Max-Age` を設定しない）— ブラウザを閉じると自動的に消去されます。
- 再訪問時に再度年齢ゲートが表示されます。

## 3. 会員登録・本人性確認

### 3.1 新規会員登録フロー

```
[/register アクセス]
      │
      ▼
[フォーム入力：氏名 / メール / パスワード]
      │
      ├─ 氏名：2 文字以上必須
      ├─ メール：RFC 5322 準拠の形式チェック
      └─ パスワード：6 文字以上、英字＋数字必須
      │
      ▼
[POST /api/users]
      │
      ├─ パスワードは scrypt+salt でハッシュ化して保存
      ├─ 既存メールチェック（重複時はエラー）
      └─ 完了時にセッション Cookie を発行（user_session）
      │
      ▼
[/profile へリダイレクト]
```

### 3.2 ログインフロー

```
[/login アクセス]
      │
      ▼
[メール＋パスワード入力]
      │
      ▼
[POST /api/user-auth]
      │
      ├─ パスワード照合（scrypt timingSafeEqual）
      ├─ セッション生成（base64(payload).hex(hmac-sha256)）
      │  payload = { userId, email, name, role, iat }
      │  TTL = 24 時間
      └─ クッキーに user_session=<token> を設定（HttpOnly, Secure, SameSite=Strict）
      │
      ▼
[/profile へリダイレクト]
```

### 3.3 セッション管理

- **ステートレス**：サーバー側にセッション状態を保存せず、JWT 様のトークンを HMAC 署名で検証
- **署名アルゴリズム**：HMAC-SHA256（Web Crypto API で実装、Edge Runtime 対応）
- **トークン形式**：`base64(json{userId,email,name,role,iat}).hex(hmac-sha256)`
- **有効期限**：24 時間（iat からの経過時間で判定）
- **クッキー属性**：
  - `HttpOnly`：JavaScript からのアクセスを禁止（XSS 対策）
  - `Secure`：HTTPS 通信でのみ送信
  - `SameSite=Strict`：CSRF 対策
  - `Path=/`：サイト全体で有効

### 3.4 会員情報管理

会員が `/profile` で以下の情報を編集できます：

| フィールド | バリデーション |
|-----------|----------------|
| 氏名 | 2 文字以上必須（trim 後） |
| メール | 変更不可（編集時に disabled） |
| 電話番号 | 数字・ハイフン・スペースのみ、10 桁以上 |
| 生年月日 | 必須、未来日不可、**20 歳以上必須**（たばこ事業法） |

入力は**フロントエンド＋バックエンドの両方で検証**し、API 直叩きによるバイパスを防ぎます。

## 5. 広告表示・健康警告

### 5.1 健康警告の表示

日本たばこ事業法施行規則第 36 条の 5 および関連通知に基づき、**たばこ商品が表示されるすべてのページに健康警告を表示**しています。

#### 警告文言（三言語統一、2026年7月から日本語のみ）

```
喫煙は肺癌、脳卒中等の疾病のリスクを高めます。未満20歳の喫煙は法律で禁止されています。
```

加熱式たばこ商品の場合：

```
加熱たばこの蒸気には発がん物質等の有害物質が含まれています。未満20歳の喫煙は法律で禁止されています。
```

#### 表示箇所と表示形式

| ページ種別 | 表示位置 | 表示形式 |
|-----------|----------|----------|
| 商品詳細ページ | メインヒーロー画像の下部 | 画像領域の **20%**（赤背景オーバーレイ・白文字・警告アイコン付き） |
| 商品一覧ページ | フィルター上部のサイト全体警告帯 | 赤帯（背景・警告アイコン・テキスト） |
| ホーム（トップ） | メインヒーロー下部のサイト全体警告帯 | 赤帯 |
| カートドロワー | 下部の注意書き | アイコン＋テキスト |

**商品詳細ページの警告帯は、商品画像領域の 20% を占めており、たばこ事業法施行規則で求められる 15% 以上を上回ります。**

### 5.2 商品ページでの健康警告オーバーレイ実装

```
┌──────────────────────────┐
│                          │
│      商品画像             │  ← 残り 80%
│      (Hero Image)         │
│                          │
├──────────────────────────┤
│  ⚠ 喫煙は肺癌、脳卒中等  │  ← 下部 20%（赤背景・白文字）
│    の疾病のリスクを高め  │
│    ます。未満20歳の喫煙  │
│    は法律で禁止されて    │
│    います。              │
└──────────────────────────┘
```

- 赤色背景（`bg-red-600`、透過度 95%）と白文字で視認性を確保
- 警告アイコン（AlertTriangle）を左端に配置
- 警告文は `line-clamp-3` で最大 3 行に制限
- `pointer-events-none` を設定し、警告帯が画像クリックを妨害しないようにしている

本サイトは**開成産業合同会社が直接運営する自社 EC サイト**であり、第三者による広告掲載や第三者 Affiliate タグは一切含まれません。

## 7. 個人情報保護

### 7.1 取得する個人情報

- 氏名・住所・電話番号・メールアドレス・生年月日
- 購入履歴
- **本人確認書類の画像データ**（運転免許証・健康保険証・マイナンバーカード・パスポート）

### 7.2 本人確認書類の取り扱い（プライバシーポリシー第 3-2 条）

| 項目 | 仕様 |
|------|------|
| 取得目的 | 法定喫煙年齢（20 歳以上）の確認および本人性の確認に限定 |
| 保管方法 | SSL/TLS 暗号化通信で送信、サーバー側では AES-256 相当の暗号化で保管 |
| アクセス制限 | 当店所定の年齢確認担当者のみ。操作ログを取得し定期的に監査 |
| 共有・第三者提供 | 法令に基づく場合を除き一切行わない（配送委託先にも共有しない） |
| 保管期間 | 確認完了後 30 日以内に完全削除 |
| ご本人様のご請求 | 保管期間中に削除をご請求いただいた場合は遅滞なく削除 |

### 7.3 その他の個人情報保護方針

- SSL/TLS 暗号化通信による全ページ HTTPS 化
- クレジットカード番号は保持せず、Stripe 等決済代行会社（将来的に連携する場合）のみが保管
- パスワードは scrypt + salt でハッシュ化して保存（平文保管なし）
- アクセスログを取得し、不正アクセスを監視
